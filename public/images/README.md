# Immagini

Cartella per le fotografie reali del sito.

Ogni immagine del progetto è oggi un `<ImagePlaceholder>` che descrive cosa
va inserito. Per sostituirla:

1. metti il file qui (es. `cantiere-01.jpg`);
2. passa `src="/images/cantiere-01.jpg"` al componente;
3. aggiorna `alt` con una descrizione reale della foto.

Proporzioni, lazy loading e layout restano invariati.

**Regole:** solo fotografie reali. Le foto di lavori precedenti dei fondatori
vanno usate esclusivamente dentro `ExperienceBlock`, che mostra il disclaimer
sull'esperienza pregressa. Non usare immagini di persone generate o di stock
presentandole come il team.
